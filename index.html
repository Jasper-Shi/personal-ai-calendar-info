Personal use · Google Calendar integration

Your calendar, in your personal activity history.

Personal AI Calendar Sync copies events from the account owner's primary Google Calendar into the owner's private Personal AI Activities database. It supports upcoming activities as well as past events, following the owner's chosen calendar-as-activity policy.

What it does

  • Reads the primary calendar across a rolling window of one year in the past and one year in the future.
  • Checks for changes approximately every 15 minutes, including rescheduling and cancellations.
  • Preserves event dates, time zones and recurring-event identity.

Access stays under the owner's control

The integration requests read-only calendar event access and a stable Google account identifier. Google's permission covers calendar events more broadly; this application only requests the primary calendar. It cannot create, edit or delete events in Google Calendar.

The owner separately controls which connected AI tools may read the private activity records. This public website contains only application information; it does not display calendar data or offer public account registration.

Read the privacy policy for data handling and revocation details.
